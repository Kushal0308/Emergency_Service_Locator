# Emergency Service Locator

An interactive, premium dashboard using optimized computer science algorithms to pair emergency requests with nearby service units.

**Off Campus Verification Code**: `JTU8GM`

🚀 **Live Deployment**: [https://emergency-service-locator.onrender.com](https://emergency-service-locator.onrender.com)

---

## Features
- **Divide & Conquer Algorithm**: Utilizes optimized $O(N \log N)$ closest-pair of points logic to pair locations.
- **Brute Force Comparison**: Compares mathematical complexity and execution time ($O(N^2)$ vs $O(N \log N)$) in real-time.
- **Dynamic Maps**: Integration with Google Maps API (New) to display active services.
- **Admin Control**: Panel to dynamically add, remove, or modify status of emergency services.

## Tech Stack
- **Backend**: Flask (Python) with Gunicorn
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism design), Vanilla JS
- **Database**: SQLite3
